GETTING STARTED

开始使用直播守望

1. 添加直播间

可直接粘贴手机抖音“分享 → 复制链接”得到的整段主页或直播文案，无需删除文字或换行；支持 v.douyin.com 短链及完整主页、直播间链接。批量粘贴多条分享时用空行分隔，纯 ID / 链接列表仍可一行一个。主页分享需要账号查询授权，可使用现有官方登录窗口扫码或手机号登录。自动识别会把数字或字母裸 ID（如 lrc568568）按直播间查询；查抖音账号请选择“抖音账号”或加 @。首次使用按提示点击“扫码登录抖音”，完成扫码后软件会自动连接并返回。暂时不方便登录可选择“稍后设置”，以后从右上角继续。

2. 开启监控与自动录制

默认开启高频状态监控：每房间检查完成后等待 8 秒再检查，总并发默认 32，抖音状态并发默认 4，单次请求超时 4 秒。只查询状态，不打开视频流；每个房间独立到期，同一房间不会重叠请求。默认开启监控进程隔离，超时后回收重建。全局探测默认最多每秒派发 20 次，抖音检查另限每秒 2 次；疑似下播会快速复核。断网、响应过慢或平台限流时仍保留最近确认结果及成功时间；顶部可查看实际间隔和请求延迟。关闭高频模式后可使用原来的独立 / 整批调度与分钟级轮间设置。手动检测会优先排队，仍遵守并发和平台受限重试。检测异常会分类写入运行日志，点击该行状态可查看详细记录。点击自动录制会先让你设置画质和存储位置，保存后检测到开播便在后台保存视频；也可以为已开播直播间统一设置并开启录制。首次监控自动查询可用的开播、下播时间；平时仅持续检查直播状态，状态变化时更新对应时间列。两列各自保留最近一次值，历史按场次保存。平台时间未取得时先显示带“检测”标记的本机时间，并后台补采准确值；缺失时延后重试，取得后停止。最小化窗口仍可继续录制和播放系统提示音。

3. 查看本地文件

录像默认每 30 分钟分段；停滞时重新取源并新建片段续录。可在直播源窗口选择当前提供的画质和格式作为录制偏好。视频默认保存在 video/直播间目录，可在默认设置或单个直播间录制设置中更改；开关播 CSV 保存在 time_begin_over/直播间目录。解析与录制错误可在运行日志中查看。

微信视频号接入说明

视频号没有按任意账号 ID 查询直播的公开接口。需要有效且有访问权限的直播源，或自己的 JSON 状态接口。仅填写视频号 ID 或分享链接无法自动查询。直播源过期后需更新。

请保持电脑联网并关闭睡眠，确保磁盘空间充足。退出使用右上角“退出软件”；关闭窗口时会结束录制并退出。详细步骤请参阅随软件提供的使用说明。

自动录制设置

留空目录时沿用默认存储位置。保存后开启自动监控和录制；已开播会开始录制，未开播等待开播。指定画质未提供时将继续取源等待，避免录错画质。已在录制时，新设置用于下一片段。
LIVE SOURCES

直播间与直播源

播放默认采用设置中的播放画质；手动更改下方画质或格式后，播放采用当前选择。下方显示平台实际提供的画质与格式，未提供的选项不可选择。保存录制偏好后在下一片段生效；该画质缺失时重新取源等待恢复。直播源链接可能随时间失效。

导出直播间列表

仅导出直播间 ID 和主页链接。选中直播间时导出选中项，未选中则导出全部；昵称、备注、监控与录制设置不导出。
